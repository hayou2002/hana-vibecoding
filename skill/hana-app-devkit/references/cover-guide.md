# 卡片封面规范

> 阶段⑤产出用。目的：让这套流程做出来的 App，**一看就知道是"我们这一系"的**。
> 核心思路：**换符号不换骨架**。

## 1. 视觉骨架（固定不变）

| 要素 | 规范 | 为什么 |
|---|---|---|
| 底色 | 深色圆角方块，垂直渐变 `#3a332c → #1e1a16` | 与面板头部品牌锚点同构，暖黑不刺眼 |
| 圆角 | 方块的 20% 左右（如 44px 方块用 13px 圆角） | 与宿主圆角体系呼应 |
| 符号 | **单色极简剪影**，颜色 `#fdfaf6`（暖白） | 不用彩色、不用花哨渐变 |
| 留白 | 符号占方块约 55~65%，四周留白 | 太小看不清，太大显拥挤 |
| 数量 | 一个符号，不叠两个 | 一眼可辨优先 |

## 2. 尺寸适配

- **主封面**（卡片中心展示）：正方形，建议 256×256 或 512×512 viewBox。
- **应用图标**：同骨架，符号略放大（65%），因小尺寸下细节会糊。
- **列表缩略图**：只保留符号，去掉渐变描边细节。
- **自适应要点**：用 SVG（矢量，任意尺寸不糊）；不要把文字做成位图。

## 3. 符号怎么选（换符号不换骨架）

符号要**一眼指向功能**，优先用行业通用意象：

| App 类型 | 可用符号 |
|---|---|
| 命令行 / 工具 | 终端提示符、齿轮、扳手 |
| 数据 / 分析 | 柱状图、折线、放大镜 |
| 网络 / 服务 | 节点连线、云、地球 |
| 文档 / 笔记 | 纸张折角、笔、书 |
| 媒体 / 图 | 音符、播放三角、相框 |
| 本开发陪练本身 | 类似「⌘ + 方块」或「工具 + 星」的组合，呼应"开发助手" |

> 避免：品牌 logo 直接搬运（版权）；多个意象拼接（看不清）；纯文字（失辨识度）。

## 4. 自检清单

- [ ] 缩到 32×32 还认得出是什么吗？
- [ ] 放在别的 App 封面旁边，风格是一家人吗？
- [ ] 去掉颜色只看剪影，语义还成立吗？
- [ ] 在深色 / 浅色宿主主题下都不发脏吗？
